3D Terrain Globe

A real global digital elevation model, rendered with CesiumJS and streamed live from AWS's public Terrain Tiles dataset — no API key, no server.

1×5×
Elevation comes from AWS's Terrain Tiles Open Data (s3://elevation-tiles-prod) in Mapzen's Terrarium encoding — global 1–30 arc-second SRTM/ETOPO1/3DEP data, PNG-encoded so elevation can be decoded from ordinary RGB pixels in the browser. Imagery is Esri World Imagery. Both are fetched directly by CesiumJS as you pan and zoom — nothing is pre-baked.
